### 🛠 Projects

**🔐 GLordAuth** – authentication plugin for **Velocity / BungeeCord** networks
- Full YAML configuration (17 config files: `methods/`, `security/`, `commands/`)
- **Discord / Telegram / VK** bot integration with button menus
- **HikariCP** connection pooling, supports **H2, MySQL, MariaDB, PostgreSQL**
- Animated title / bossbar UI, **MiniMessage** colors
- Security and stability work: SQL injection fixes, race conditions, cross-server player detection, session management

**🏷 TitleCore** – prefix and moderation plugin for **Paper 1.20+**
- Token-based custom prefix system
- Ticket moderation GUI
- **LuckPerms** integration
- **SQLite / MySQL** storage
- Fully localized in Russian

**⚔️ ArenaCore** – PvP plugin with **FFA arenas** and arena management

**🏷 TitleCore** – плагин префиксов и модерации для **Paper 1.20+**
